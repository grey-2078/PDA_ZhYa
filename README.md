# Сбор и агрегация данных о книгах 

В рамках данной лабораторной работы реализованы сбор и агрегация данных с вебресурса Open Library. 

Сбор данных осуществляется с помощью библиотеки Scrapy, а для их хранения применяется база данных SQLite с использованием SQLAlchemy. 

## Используемые технологии 

- **Python** 
- **Scrapy 2.19.0** 
- **SQLAlchemy 2.1.3** 
- **SQLite** 

## Структура проекта 

``` 
    PDA_ZhYa/ 
    │ 
    ├── scrapy.cfg              # Конфигурационный файл проекта Scrapy 
    ├── requirements.txt        # Зависимости проекта 
    ├── README.md               # Отчет 
    ├── books_project/ 
    │   └── __init__.py         # Пустой файл, инициализирующий директорию как пакет Python 
    │   └── settings.py         # Файл настроек проекта 
    │   └── models.py.          # Сохранение данных в БД SQLite 
    │   └── spiders/ 
    │       └── __init__.py     # Пустой файл, инициализирующий директорию как пакет Python 
    │       └── scraper.py      # Сбор данных с Open Library 
    └── venv/ 
 ``` 

## Собираемые данные 

| Поле | Описание | 
| ----------- | ----------- | 
| id | Уникальный идентификатор записи в БД | 
| title | Название книги | 
| author | Автор книги | 
| year | Год первой публикации | 
| edition_count | Количество изданий | 
| book_key | Уникальный ключ книги в Open Library | 

# Установка и настройка 

Создание виртуального окружения: 

``` python -m venv .venv ``` 

Активация виртуального окружения: 

``` source venv/bin/activate ``` 

Установка зависимостей: 

``` pip install -r requirements.txt ``` 

# Запуск сбора данных 

Для запуска необходимо выполнить: 

``` python -m scrapy crawl books ``` 

Полученные данные сохраняются в файл **books.db**. 

# Повторный запуск 

При повторном запуске программы уже существующие книги не добавляются снова. Для определения уникальности используется поле **book_key**.
